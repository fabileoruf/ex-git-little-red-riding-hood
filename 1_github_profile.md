# GitHub Profile

## Descripción
Crea tu cuenta de GitHub. (https://github.com/)

## Instrucciones
Crea tu primer repositorio.

Una vez tengas el perfil y tu primer repositorio creado realiza la entrega.

### Consejos para tu nombre de usuario
- **Profesionalidad:** Usa tu nombre real o una variación (ej: `nombreapellido`, `inicial.apellido`).
- **Consistencia:** Intenta que coincida con tu URL de LinkedIn.
- **Claridad:** Evita números aleatorios (como `user12345`) o apodos de videojuegos.
- **Legibilidad:** Que sea fácil de leer y escribir.
